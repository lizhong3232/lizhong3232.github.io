DIFFUSION TRANSFORMER ARCHITECTURE

DiT 与 MM-DiT 架构精解：从 Peebles DiT 到 SD3 / Flux.1 双流联合注意力

Diffusion Transformer (DiT) 彻底终结了 UNet 在视觉生成领域的统治地位。本文深入拆解 Patchify 机制、adaLN-Zero 零初始化自适应调制、SD3 的 MM-DiT 双流联合注意力和 Flux.1 的 QK-Norm 防熵坍塌机制，并提供完整的工业级 PyTorch 代码实现。

1 核心动机：为什么 DiT 能全面取代 UNet？(The "Why")

1. 严密的 Scaling Law

UNet 复杂的上下采样与残差连接阻碍了模型参数扩展；DiT 是均一纯 Transformer 堆叠，模型容量（FLOPs）与 FID 生成质量成极强的单调线性提升。

2. 移除卷积归纳偏置

卷积核的局部平移不变性限制了长程语义全局构图，而 Transformer 的全局注意力天然具备理解整幅画面复杂几何与物理逻辑的能力。

3. 统一多模态基础设施

DiT 可以无缝共享 LLM 领域最先进的并行基建（FlashAttention-3、Ring Attention、DeepSpeed ZeRO、Tensor Parallelism）。

2 核心机制数学拆解：adaLN-Zero 与 MM-DiT 双流

2.1 adaLN-Zero (自适应层归一化与零初始化门控)

时间步 $t$ 和文本条件 $c$ 经 MLP 投影出 6 个缩放、平移与门控参数 $(\gamma_1, \beta_1, \alpha_1, \gamma_2, \beta_2, \alpha_2)$：

$$\hat{x} = \text{LayerNorm}(x) \cdot (1 + \gamma_1) + \beta_1$$ $$x_{\text{attn}} = x + \alpha_1 \cdot \text{Attention}(\hat{x})$$ $$\tilde{x} = \text{LayerNorm}(x_{\text{attn}}) \cdot (1 + \gamma_2) + \beta_2$$ $$x_{\text{out}} = x_{\text{attn}} + \alpha_2 \cdot \text{MLP}(\tilde{x})$$

✨ 核心奥秘：将门控参数 $\alpha_1, \alpha_2$ 的线性层初始权重设为全零！初始时 $\alpha_1=\alpha_2=0$，整层输出直接为恒等映射 $x_{\text{out}}=x$，使得上百层极深 DiT 训练如丝般平滑，绝不梯度爆炸！

2.2 MM-DiT 双流联合注意力 (SD3 / Flux.1)

传统文生图使用单独的 Cross-Attention 模块，导致图像和文本无法双向深度对齐。MM-DiT 创新性地将文本 Token $T$ 与图像 Token $I$ 拼合在同一序列中做联合自注意力：

$$Q = \text{Concat}(Q_{\text{img}}, Q_{\text{text}}), \quad K = \text{Concat}(K_{\text{img}}, K_{\text{text}}), \quad V = \text{Concat}(V_{\text{img}}, V_{\text{text}})$$

在注意力计算之后，图像流和文本流各自拆开，分别走各自专用的 MLP 前馈网络，兼顾了图文联合双向交互与模态异构表征独立性！

3 PyTorch 工业级 DiT 与 MM-DiT Block 代码实现 (含逐行精讲) 

import torch
import torch.nn as nn
from typing import Tuple

def modulate(x: torch.Tensor, shift: torch.Tensor, scale: torch.Tensor) -> torch.Tensor:
    """自适应缩放平移公式: x * (1 + scale) + shift"""
    return x * (1 + scale.unsqueeze(1)) + shift.unsqueeze(1)

class DiTBlock(nn.Module):
    """
    Peebles & Xie 经典 DiT 基础模块 (含 adaLN-Zero 机制)
    """
    def __init__(self, hidden_dim: int, num_heads: int, mlp_ratio: float = 4.0):
        super().__init__()
        self.norm1 = nn.LayerNorm(hidden_dim, elementwise_affine=False, eps=1e-6)
        self.attn = nn.MultiheadAttention(hidden_dim, num_heads, batch_first=True)
        
        self.norm2 = nn.LayerNorm(hidden_dim, elementwise_affine=False, eps=1e-6)
        mlp_hidden_dim = int(hidden_dim * mlp_ratio)
        self.mlp = nn.Sequential(
            nn.Linear(hidden_dim, mlp_hidden_dim),
            nn.GELU(approximate="tanh"),
            nn.Linear(mlp_hidden_dim, hidden_dim)
        )
        
        # adaLN 调制层: 从时间/条件嵌入 c 预测 6 个调制参数 (shift_msa, scale_msa, gate_msa, shift_mlp, scale_mlp, gate_mlp)
        self.adaLN_modulation = nn.Sequential(
            nn.SiLU(),
            nn.Linear(hidden_dim, 6 * hidden_dim, bias=True)
        )
        # 核心: 将线性投影层的权重和偏置初始化为 0 (Zero-Init)
        nn.init.zeros_(self.adaLN_modulation[1].weight)
        nn.init.zeros_(self.adaLN_modulation[1].bias)

    def forward(self, x: torch.Tensor, c: torch.Tensor) -> torch.Tensor:
        """
        - x: [Batch, Seq_Len, Hidden_Dim] 图像 Patch 潜码
        - c: [Batch, Hidden_Dim] 时间步 t 与类别/文本组合嵌入
        """
        # 1. 获得 6 个调制系数
        shift_msa, scale_msa, gate_msa, shift_mlp, scale_mlp, gate_mlp = self.adaLN_modulation(c).chunk(6, dim=1)
        
        # 2. 自注意力分支 (使用 adaLN 调制与零初始化门控 gate_msa)
        norm_x = modulate(self.norm1(x), shift_msa, scale_msa)
        attn_out, _ = self.attn(norm_x, norm_x, norm_x)
        x = x + gate_msa.unsqueeze(1) * attn_out
        
        # 3. 前馈 MLP 分支 (使用 adaLN 调制与零初始化门控 gate_mlp)
        norm_x2 = modulate(self.norm2(x), shift_mlp, scale_mlp)
        mlp_out = self.mlp(norm_x2)
        x = x + gate_mlp.unsqueeze(1) * mlp_out
        
        return x

class MMDiTJointBlock(nn.Module):
    """
    SD3 / Flux 核心: MM-DiT 双流联合注意力模块
    """
    def __init__(self, img_dim: int, txt_dim: int, num_heads: int):
        super().__init__()
        self.num_heads = num_heads
        self.head_dim = img_dim // num_heads
        
        # 图像流与文本流各自的 Q, K, V 投影矩阵
        self.img_qkv = nn.Linear(img_dim, img_dim * 3, bias=False)
        self.txt_qkv = nn.Linear(txt_dim, txt_dim * 3, bias=False)
        
        # 图像与文本各自独立的输出投影与 MLP
        self.img_out = nn.Linear(img_dim, img_dim)
        self.txt_out = nn.Linear(txt_dim, txt_dim)

    def forward(self, img_tokens: torch.Tensor, txt_tokens: torch.Tensor) -> Tuple[torch.Tensor, torch.Tensor]:
        """
        - img_tokens: [B, N_img, Dim]
        - txt_tokens: [B, N_txt, Dim]
        """
        B, N_img, D = img_tokens.shape
        _, N_txt, _ = txt_tokens.shape
        
        # 1. 分别计算图像与文本的 Q, K, V
        q_img, k_img, v_img = self.img_qkv(img_tokens).chunk(3, dim=-1)
        q_txt, k_txt, v_txt = self.txt_qkv(txt_tokens).chunk(3, dim=-1)
        
        # 2. 拼合成联合序列 [B, N_img + N_txt, D]
        q_joint = torch.cat([q_img, q_txt], dim=1).view(B, N_img + N_txt, self.num_heads, self.head_dim).transpose(1, 2)
        k_joint = torch.cat([k_img, k_txt], dim=1).view(B, N_img + N_txt, self.num_heads, self.head_dim).transpose(1, 2)
        v_joint = torch.cat([v_img, v_txt], dim=1).view(B, N_img + N_txt, self.num_heads, self.head_dim).transpose(1, 2)
        
        # 3. 联合全量缩放点积注意力
        scores = torch.matmul(q_joint, k_joint.transpose(-2, -1)) / (self.head_dim ** 0.5)
        attn = torch.softmax(scores, dim=-1)
        joint_out = torch.matmul(attn, v_joint).transpose(1, 2).reshape(B, N_img + N_txt, D)
        
        # 4. 分流恢复: 图像与文本分别拆开并通过各自的线性层
        img_out = self.img_out(joint_out[:, :N_img, :])
        txt_out = self.txt_out(joint_out[:, N_img:, :])
        
        return img_out, txt_out

# 快速验证 Tensor 流动

    dit = DiTBlock(hidden_dim=256, num_heads=8)
    x = torch.randn(2, 64, 256) # [B=2, 64个Patch, Dim=256]
    c = torch.randn(2, 256)     # [B=2, 条件向量]
    out = dit(x, c)
    print("DiT Block 输出形状:", out.shape) # [2, 64, 256]

4 工业实战避坑指南 (Pitfalls)

避坑 1: adaLN 未做 Zero-init 导致深层网络训练立即发散

若未将 adaLN 线性层权重置 0，随机初始化的门控参数会在第一步反向传播中传递巨大的方差梯度，导致损失直接变为 NaN。

避坑 2: Flux.1 必须开启 QK-Normalization

在大参数量（12B）DiT 中，未归一化的 QK 点积极大值容易随层数指数级增长。引入 QK-Norm（在点积前对 Q 和 K 做 RMSNorm）可彻底杜绝注意力权重坍塌。

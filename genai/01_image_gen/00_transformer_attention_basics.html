FOUNDATION ARCHITECTURE

Transformer 与注意力机制全景基石

自注意力机制（Self-Attention）是现代大模型（LLM / DiT / MM-DiT）的算力与表征心脏。本文从软寻址物理直觉、缩放点积推导、多头注意力 (MHA)、跨模态交叉注意力 (Cross-Attention) 到 FlashAttention 硬件加速做透彻拆解。

1 核心动机：为什么注意力机制能颠覆深度学习？(The "Why")

注意力的物理直觉：可微分的“软字典检索 (Soft Key-Value Lookup)”

在传统 Python 字典中，通过一个 Key 只能硬性匹配一个固定的 Value。而在深度学习中，注意力机制实现了模糊软匹配：

Query (Q, 查询需求)

“我当前这个 Token 需要找什么特征？”（例如：图像中狗的头部想找狗的尾巴）。

Key (K, 索引标签)

“我是其他位置的 Token，我具有什么特征标签？”（例如：我是草地、我是天空、我是尾巴）。

Value (V, 实际内容)

“如果匹配上了，我能提供什么高维语义特征？”（传递具体的纹理与颜色嵌入）。

对比 CNN 与 RNN 的决定性优势：CNN 视野受限于卷积核局部感受野（需堆叠几十层才能看全局），RNN 必须时间串行递归（无法并行且长程梯度消失）。Attention 拥有 $\mathcal{O}(1)$ 的全局直接通信距离与极致的 GPU 并行吞吐！

2 严谨数学公式拆解 (KaTeX Math)

2.1 缩放点积注意力 (Scaled Dot-Product Attention)

$$\text{Attention}(Q, K, V) = \text{softmax}\left( \frac{Q K^T}{\sqrt{d_k}} \right) V$$

面试高频必问：为什么必须除以缩放因子 $\sqrt{d_k}$？

假设 $q$ 和 $k$ 的每个分量都是独立同分布的均值为 0、方差为 1 的随机变量。点积 $q \cdot k = \sum_{i=1}^{d_k} q_i k_i$ 的方差为： $$\text{Var}\left( \sum_{i=1}^{d_k} q_i k_i \right) = \sum_{i=1}^{d_k} \text{Var}(q_i k_i) = d_k \cdot 1 = d_k$$ 当特征维度 $d_k$ 很大（如 64 或 128）时，点积数值的绝对值会变得极大，导致 Softmax 函数进入两端导数极小的平坦饱和区（梯度几乎为 0，发生梯度消失）！除以 $\sqrt{d_k}$ 将方差重新缩放回 1，保证 Softmax 处于对输入变化最敏感的健康梯度区。

2.2 多头注意力机制 (Multi-Head Attention, MHA)

单头注意力只能关注一种空间关系模式。多头机制将高维空间投影到 $h$ 个低维子空间，分别独立计算注意力并拼接：

$$\text{MHA}(Q, K, V) = \text{Concat}(\text{head}_1, \dots, \text{head}_h) W^O$$ $$\text{where} \quad \text{head}_i = \text{Attention}(Q W_i^Q, K W_i^K, V W_i^V)$$

其中投影矩阵 $W_i^Q \in \mathbb{R}^{d_{\text{model}} \times d_k}, \ W_i^K \in \mathbb{R}^{d_{\text{model}} \times d_k}, \ W_i^V \in \mathbb{R}^{d_{\text{model}} \times d_v}, \ W^O \in \mathbb{R}^{h d_v \times d_{\text{model}}}$。

2.3 跨模态交叉注意力 (Cross-Attention in Image/Video DiT)

在文生图（Stable Diffusion / DiT）中，文本描述是如何注入图像生成的？

Self-Attention (图像自注意力)
$Q = x_{\text{img}} W^Q, \ K = x_{\text{img}} W^K, \ V = x_{\text{img}} W^V$

图像内部不同 Patch 互相感知空间几何。

Cross-Attention (图文交叉注意力)
$Q = x_{\text{img}} W^Q, \ K = c_{\text{text}} W^K, \ V = c_{\text{text}} W^V$

图像主动向文本特征 $c$ 索取语义指引！

3 PyTorch 工业级自注意力与交叉注意力代码实现 (Code Walkthrough) 

import math
import torch
import torch.nn as nn
from typing import Optional

class MultiHeadCrossAttention(nn.Module):
    """
    自包含的工业级多头自注意力 / 交叉注意力模块 (PyTorch)
    """
    def __init__(self, d_model: int, num_heads: int, d_context: Optional[int] = None):
        super().__init__()
        assert d_model % num_heads == 0, "d_model 必须能被 num_heads 整除"
        self.d_model = d_model
        self.num_heads = num_heads
        self.d_k = d_model // num_heads
        
        # 支持交叉注意力: Context 维度可以与 d_model 不同
        d_ctx = d_context if d_context is not None else d_model
        
        # 1. 线性投影矩阵
        self.w_q = nn.Linear(d_model, d_model, bias=False)
        self.w_k = nn.Linear(d_ctx, d_model, bias=False)
        self.w_v = nn.Linear(d_ctx, d_model, bias=False)
        self.w_o = nn.Linear(d_model, d_model, bias=False)

    def forward(self, x: torch.Tensor, context: Optional[torch.Tensor] = None, mask: Optional[torch.Tensor] = None) -> torch.Tensor:
        """
        x: [B, Seq_Q, d_model] - 图像或潜码 Token
        context: [B, Seq_KV, d_context] - 文本条件 (为 None 时自动退化为 Self-Attention)
        """
        B, Seq_Q, _ = x.shape
        ctx = context if context is not None else x
        Seq_KV = ctx.shape[1]

        # 2. 投影并分头 [B, Seq, d_model] -> [B, Num_Heads, Seq, d_k]
        Q = self.w_q(x).view(B, Seq_Q, self.num_heads, self.d_k).transpose(1, 2)
        K = self.w_k(ctx).view(B, Seq_KV, self.num_heads, self.d_k).transpose(1, 2)
        V = self.w_v(ctx).view(B, Seq_KV, self.num_heads, self.d_k).transpose(1, 2)

        # 3. 缩放点积注意力 Scores = (Q * K^T) / sqrt(d_k)
        scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(self.d_k) # [B, Heads, Seq_Q, Seq_KV]

        if mask is not None:
            scores = scores.masked_fill(mask == 0, -1e9)

        # 4. Softmax 归一化注意力权重
        attn_weights = torch.softmax(scores, dim=-1)

        # 5. 加权汇聚 Value 并多头合并
        out = torch.matmul(attn_weights, V) # [B, Heads, Seq_Q, d_k]
        out = out.transpose(1, 2).contiguous().view(B, Seq_Q, self.d_model) # [B, Seq_Q, d_model]

        # 6. 最终线性输出投影
        return self.w_o(out)

# 快速验证 Tensor 维度
if __name__ == "__main__":
    attn = MultiHeadCrossAttention(d_model=512, num_heads=8, d_context=768)
    
    # 模拟图像 Token (B=2, 256个Patch, dim=512)
    img_tokens = torch.randn(2, 256, 512)
    # 模拟文本 CLIP Token (B=2, 77个词, dim=768)
    text_tokens = torch.randn(2, 77, 768)
    
    # 交叉注意力输出
    out = attn(img_tokens, context=text_tokens)
    print("Cross-Attention Output Shape:", out.shape) # 严格保持 [2, 256, 512]

4 FlashAttention 硬件 IO 加速原理精讲 (IO-Awareness)

为什么标准 Attention 会成为计算瓶颈？

传统 PyTorch 计算 Attention 时，必须把巨大的中间矩阵 $S = Q K^T \in \mathbb{R}^{N \times N}$ 和 $P = \text{softmax}(S)$ 写入显存（HBM），然后再读回计算 $P V$。对于 $N=100k$ 的视频序列，显存读写瓶颈 (Memory-Bound) 极其严重！

FlashAttention 的两大破局核心：

1. Tiling (分块加载到片上 SRAM)：将 $Q, K, V$ 按照 GPU 的高速片上 SRAM 缓存大小切成小块（如 $128 \times 128$），在极速的 SRAM 内部完成局部矩阵乘法。

2. Online Softmax (在线 Softmax 统计量递推更新)：利用数学递推公式，在分块计算的同时动态维护局部最大值 $m(x)$ 和指数和 $l(x)$，完全不需要物化保存完整的 $N \times N$ 注意力矩阵！显存从 $\mathcal{O}(N^2)$ 骤降至 $\mathcal{O}(N)$，速度提升 2~4 倍！

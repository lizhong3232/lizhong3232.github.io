High-Yield Interview Master Cheatsheet

顶级大厂 MLE / GenAI Researcher 高频考点速记

Q1: 视频生成中，为什么不能把每一帧当作独立图像分别生成？

核心答点：独立帧生成会导致严重的时间闪烁 (Temporal Flickering) 与物理规律违背。视频本质是时空连续流形，必须通过 3D Causal VAE 压缩时间冗余，并通过时空注意力（Temporal Attention）强制相邻帧之间维持严格的光流与运动轨迹一致性。

Q2: 什么是 3D Causal VAE？与 2D VAE 相比为什么必须满足因果性？

核心答点：标准 3D 卷积在时间维是对称的（同时看过去和未来帧），这导致：1. 无法实现流式实时推理；2. 第一帧会受到未来噪声帧的污染。Causal（因果）卷积强制每一时刻只聚合 $t \le \tau$ 的过去信息，保证时间箭头的单向性，天然兼容长视频自回归扩展。

Q3: 图像-视频生成 (I2V) 中，首帧条件注入有哪两种主流方式？优劣是什么？

核心答点：
1. 通道拼接 (Channel Concatenation)：将首帧潜码与噪声在通道维拼叠。保真度极高、首帧纹理严格锁定，但动作变化范围受限。
2. 交叉注意力 (Cross-Attention Conditioning)：将首帧经过 CLIP 提取特征作为 Key-Value 注入。动作幅度大、自由度高，但首帧细节可能产生微小漂移。

Q4: 为什么 DiT (Diffusion Transformer) 能够彻底取代 UNet？

核心答点：
1. 严格遵循 Scaling Law：UNet 包含复杂的下采样/上采样与残差连接，堆叠参数无法有效转化为生成质量；DiT 是标准纯 Transformer 堆叠，算力与质量成极强线性正比。
2. 多模态无缝融合：天然支持文本 Token 与图像/视频 Token 的跨模态联合注意力。
3. 完美复用成熟基建：直接享受 FlashAttention、Megatron 并行、ZeRO 等 LLM 领域成熟的基础设施加速。

时空 3D DiT 架构：从 2D Patchify 到 4D 联合注意力

视频本质上是时空连续的 4D 张量 $(B, T, C, H, W)$。本专题深入拆解视频 3D Patchify 机制、解耦时空注意力 (Factorized Space-Time Attention) 与 3D 旋转位置编码 (3D RoPE)。

1 核心动机：视频 Token 爆炸与时空分解 (The "Why")

为什么不能直接对 4D 视频做朴素全注意力 (Full 3D Attention)？

假设一段 5 秒 24 FPS 的高清视频（120 帧，分辨率 $1024 \times 1024$），经过 2D Patchify ($16 \times 16$) 后：
Token 总数 $N = 120 \times (64 \times 64) \approx 491,520$ 个 Token！
标准自注意力显存复杂度为 $O(N^2) \approx 2.4 \times 10^{11}$ 次浮点运算，单张 H100 显存瞬间 OOM 爆炸成千上万倍！

破局核心解法：

1. 3D Patchification：在时间维也做 Patch 压缩（如 $2 \times 16 \times 16$），将时间序列减半。
2. 分因子时空解耦注意力 (Factorized Attention)：先在空间内做 Self-Attention ($O(H W)^2$)，再沿时间轴跨帧做 Temporal Attention ($O(T^2)$)，将二次方爆炸降为线性乘积！

2 时空注意力数学形式与 3D RoPE (KaTeX Math)

2.1 解耦时空注意力 (Factorized Space-Time Attention)

将输入潜码 $Z \in \mathbb{R}^{B \times T \times S \times D}$（其中 $S = H \times W$ 是空间 Token 数）：

// 步骤 1: 空间自注意力 (Spatial Attention - 每一帧内部)

$Z_{\text{spatial}} = \text{Attention}(\text{reshape}(Z, (BT, S, D))) \in \mathbb{R}^{BT \times S \times D}$

// 步骤 2: 时间自注意力 (Temporal Attention - 跨帧轨迹捕捉)

$Z_{\text{temporal}} = \text{Attention}(\text{transpose}(Z_{\text{spatial}}, (BS, T, D))) \in \mathbb{R}^{BS \times T \times D}$

计算量对比：从 $O((T \cdot S)^2)$ 骤降至 $O(T \cdot S^2 + S \cdot T^2)$，节约 99% 以上显存！

2.2 3D 旋转位置编码 (3D Rotary Position Embedding / 3D RoPE)

在视频生成中，传统的 1D 或 2D 绝对位置编码无法泛化到任意帧率和长宽比。Wan 2.1 与 Sora 采用 3D RoPE：

$$\mathbf{R}_{3D}(t, h, w) = \text{diag}\Big( \mathbf{R}_{\text{time}}(t), \ \mathbf{R}_{\text{height}}(h), \ \mathbf{R}_{\text{width}}(w) \Big)$$

将特征通道维度 $D$ 均分为 3 份，分别应用时间、高度、宽度的旋转变换矩阵，天然支持可变分辨率与可变帧率推理！

3 PyTorch 极简时空 DiT Block 代码实现 (Code Walkthrough) 

import torch
import torch.nn as nn
from einops import rearrange

class SpatioTemporalDiTBlock(nn.Module):
    """
    工业级时空解耦 DiT 模块 (Factorized Space-Time DiT Block)
    """
    def __init__(self, hidden_dim: int, num_heads: int):
        super().__init__()
        # 1. 空间注意力 (Spatial Self-Attention)
        self.spatial_norm = nn.LayerNorm(hidden_dim)
        self.spatial_attn = nn.MultiheadAttention(hidden_dim, num_heads, batch_first=True)
        
        # 2. 时间注意力 (Temporal Self-Attention)
        self.temporal_norm = nn.LayerNorm(hidden_dim)
        self.temporal_attn = nn.MultiheadAttention(hidden_dim, num_heads, batch_first=True)
        
        # 3. 前馈网络 (MLP)
        self.mlp_norm = nn.LayerNorm(hidden_dim)
        self.mlp = nn.Sequential(
            nn.Linear(hidden_dim, hidden_dim * 4),
            nn.GELU(),
            nn.Linear(hidden_dim * 4, hidden_dim)
        )

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        """
        x: [B, T, H, W, D] 4D 视频潜码 Token
        """
        B, T, H, W, D = x.shape
        S = H * W  # 空间 Token 总数

        # === 1. 空间自注意力 (每一帧内部独立做 Attention) ===
        # 将 [B, T, H, W, D] -> [B * T, S, D]
        x_space = rearrange(x, 'b t h w d -> (b t) (h w) d')
        norm_space = self.spatial_norm(x_space)
        attn_out_space, _ = self.spatial_attn(norm_space, norm_space, norm_space)
        x_space = x_space + attn_out_space

        # === 2. 时间自注意力 (每个空间位置跨时间帧做 Attention) ===
        # 将 [B * T, S, D] -> [B * S, T, D]
        x_time = rearrange(x_space, '(b t) s d -> (b s) t d', b=B, t=T, s=S)
        norm_time = self.temporal_norm(x_time)
        attn_out_time, _ = self.temporal_attn(norm_time, norm_time, norm_time)
        x_time = x_time + attn_out_time

        # === 3. MLP 前馈与残差恢复 ===
        # 恢复回原始形状 [B, T, H, W, D]
        x_out = rearrange(x_time, '(b h w) t d -> b t h w d', b=B, h=H, w=W)
        x_out = x_out + self.mlp(self.mlp_norm(x_out))
        
        return x_out

# 快速验证 Tensor 维度流动
if __name__ == "__main__":
    block = SpatioTemporalDiTBlock(hidden_dim=256, num_heads=8)
    video_tokens = torch.randn(2, 8, 16, 16, 256) # [B=2, T=8帧, H=16, W=16, D=256]
    out = block(video_tokens)
    print("Output Video Shape:", out.shape) # 严格保持 [2, 8, 16, 16, 256]

4 工业界实战避坑指南 (Pitfalls)

陷阱 1：时间注意力初始化为随机大权重导致崩塌

如果直接从预训练 2D 图像 DiT 加载权重并新增时间注意力层，初始时时间层的随机输出会彻底破坏预训练的单帧画质！
工业解决方案：将时间注意力最后一层投影矩阵的权重初始化为 全零 (Zero-init)，保证训练初始时网络严格等价于 2D 图像模型，随后平滑学习时序动态。

方案 2：时间维度必须应用因果或双向注意力？

在纯文本到视频 (T2V) 生成中，通常使用双向时空注意力（前后帧互相感知）以保证最高画质；而在流式长视频生成或自回归续写中，时间维必须使用因果 Mask（Causal Mask）防止未来信息穿越。

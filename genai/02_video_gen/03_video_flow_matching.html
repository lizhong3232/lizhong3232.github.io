4D VELOCITY FIELD & I2V CONDITIONING

视频流匹配与 I2V 条件控制：4D 速度场与首帧引导机制

现代视频大模型（Wan 2.1 / HunyuanVideo / MovieGen）全面转向 4D 时空流匹配（Video Flow Matching）。本文解构 4D 速度场回归、首帧拼接 (Channel Concatenation) 与相机运镜控制 (Camera Motion LoRA)。

1 4D 时空速度场：从图片流到时空连续流 (The "Why")

在 4D 时空连续概率流中，每个时空位置 $(t, x, y, z)$ 的流动速度 $v_\theta(Z_\tau, \tau)$ 决定了整段视频从纯高斯白噪声向连续光流运动演化的确定性轨迹。

2 I2V 首帧条件注入两大范式对比 (KaTeX Math)

范式 A: 通道拼接 (Channel Concatenation)

将首帧图像潜码 $z_{\text{img}}$ 在通道维直接与噪声 $z_\tau$ 拼叠： $$Z_{\text{input}} = \text{Concat}\big(z_\tau, \ [z_{\text{img}}, \mathbf{0}, \dots, \mathbf{0}], \ \text{mask}\big)$$ • 优势：首帧纹理严格锁定 100% 不失真，工业落地最稳定。

范式 B: 交叉注意力 (Cross-Attention)

首帧通过 CLIP / DINO 提取高维 Visual Tokens 作为 Key/Value 注入： $$Q = Z_\tau W^Q, \quad K = \text{Encoder}(I_0) W^K, \quad V = \text{Encoder}(I_0) W^V$$ • 优势：支持超大动态大幅度位移动作。

3 PyTorch 视频流匹配与 I2V 训练损失实现 (Code Walkthrough) 

import torch
import torch.nn as nn

class VideoFlowMatchingLoss(nn.Module):
    """
    4D 时空流匹配与 I2V 条件训练损失 (PyTorch)
    """
    def __init__(self, model: nn.Module):
        super().__init__()
        self.model = model

    def forward(self, x_1: torch.Tensor, first_frame: torch.Tensor) -> torch.Tensor:
        """
        - x_1: [B, C, T, H, W] 真实清晰视频潜码
        - first_frame: [B, C, H, W] 首帧参考图
        """
        B, C, T, H, W = x_1.shape
        device = x_1.device

        # 1. 采样初始高斯噪声 x_0 ~ N(0, I)
        x_0 = torch.randn_like(x_1)

        # 2. 采样连续时间步 tau in [0, 1]
        tau = torch.rand((B, 1, 1, 1, 1), device=device)

        # 3. 构造直线概率路径 x_tau = (1 - tau) * x_0 + tau * x_1
        x_tau = (1.0 - tau) * x_0 + tau * x_1

        # 4. 真实目标速度场 u_tau = x_1 - x_0 (恒定直线速度)
        target_velocity = x_1 - x_0

        # 5. 构造 I2V 条件拼接张量: 将首帧扩展为 [B, C, T, H, W] 并与 x_tau 拼接
        cond_frames = torch.zeros_like(x_1)
        cond_frames[:, :, 0, :, :] = first_frame # 仅第一帧填充
        
        # 6. 模型预测 4D 速度向量场 v_pred
        v_pred = self.model(x_tau, cond_frames, tau.squeeze())

        # 7. 回归均方误差 Loss
        return torch.mean((v_pred - target_velocity) ** 2)

# 快速验证 Tensor 维度流动
if __name__ == "__main__":
    toy_model = nn.Conv3d(16 * 2, 16, 3, padding=1) # 假定接受 [x_tau, cond] 32 通道
    def forward_fn(x, cond, t): return toy_model(torch.cat([x, cond], dim=1))
    
    loss_fn = VideoFlowMatchingLoss(model=forward_fn)
    real_video = torch.randn(2, 16, 8, 32, 32)
    img_0 = torch.randn(2, 16, 32, 32)
    loss = loss_fn(real_video, img_0)
    print("Video Flow Matching I2V Loss:", loss.item())

3D Causal VAE：时间因果卷积与时空高效压缩

视频在像素空间直接扩散会耗尽显存。3D Causal VAE 将高维视频 $(T, H, W, 3)$ 压缩至低维潜空间 $(T/4, H/8, W/8, 16)$。本文深入拆解为什么时间轴必须严格满足因果性 (Causal)、时空非对称卷积 Padding 与流式分块解码。

1 核心动机：为什么 3D VAE 必须具备“时间因果性”？(The "Why")

非因果标准 3D 卷积的缺陷

标准 3D 卷积在时间维是对称 Padding（每一帧同时看过去帧和未来帧）。这导致：
1. 无法实现流式实时推理；
2. 首帧会受到未来帧信息污染，导致首帧图像生成失真；
3. 无法兼容自回归长视频生成。

Causal 因果卷积的突破

时间维采用左单侧 Padding，当前时刻 $t$ 的卷积核严格只聚合 $\tau \le t$ 的历史与当前帧，保证时间单向流动，且当 $T=1$ 时严格等价于标准 2D 图像 VAE！

2 数学形式与非对称时空 Padding (KaTeX Math)

设 3D 卷积核尺寸为 $(K_t, K_h, K_w) = (3, 3, 3)$：

空间维度 (对称 Padding)
$\text{Pad}_{\text{height}} = (1, 1), \quad \text{Pad}_{\text{width}} = (1, 1)$
时间维度 (非对称因果 Padding)
$\text{Pad}_{\text{temporal}} = (\text{Left}=K_t - 1, \ \text{Right}=0) = (2, 0)$

在卷积输出时，剔除右侧未来维度，确保第 $t$ 帧的特征仅依赖于 $0, 1, \dots, t$ 帧。

3 PyTorch 工业级 CausalConv3d 与时空下采样实现 (Code Walkthrough) 

import torch
import torch.nn as nn
import torch.nn.functional as F

class CausalConv3d(nn.Module):
    """
    3D 时间因果卷积 (Causal 3D Convolution)
    时间维只看过去，不看未来！
    """
    def __init__(self, in_channels: int, out_channels: int, kernel_size=(3, 3, 3), stride=(1, 1, 1), **kwargs):
        super().__init__()
        self.kt, self.kh, self.kw = kernel_size
        self.st, self.sh, self.sw = stride
        
        # 空间使用对称 padding, 时间维手动做左单侧 padding
        self.conv = nn.Conv3d(
            in_channels, out_channels,
            kernel_size=(self.kt, self.kh, self.kw),
            stride=(self.st, self.sh, self.sw),
            padding=(0, self.kh // 2, self.kw // 2),
            **kwargs
        )

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        """
        - x: [B, C, T, H, W] 5D 视频张量
        """
        # 时间维进行非对称因果 Padding: (left=0, right=0, top=0, bottom=0, front=kt-1, back=0)
        # F.pad 顺序从最后一个维度往前: (w_left, w_right, h_top, h_bottom, t_front, t_back)
        time_pad = (0, 0, 0, 0, self.kt - 1, 0)
        x_padded = F.pad(x, time_pad, mode='replicate')
        return self.conv(x_padded)

# 快速验证因果性与张量维度流动
if __name__ == "__main__":
    conv = CausalConv3d(in_channels=3, out_channels=16, kernel_size=(3, 3, 3))
    video = torch.randn(2, 3, 8, 64, 64) # [B=2, C=3, T=8帧, H=64, W=64]
    out = conv(video)
    print("3D Causal Conv 输出形状:", out.shape) # 严格保持 [2, 16, 8, 64, 64] 时间帧数不漂移
